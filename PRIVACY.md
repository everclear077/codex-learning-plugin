# Privacy

This repository does not operate a backend, analytics endpoint or telemetry service. The Python exporter performs local file conversion only and needs no API key.

Tutoring happens inside Codex. Prompts, supplied files and generated content remain subject to the host application's and model provider's policies. If the agent browses external sources or uses other tools, those services may receive the relevant requests. No claim of offline or entirely on-device model inference is made.

When asked to maintain a course, the skill may save goals, answer summaries, mistakes, assistance used and artifacts in the user's selected workspace. Plugin caches are not used for personal progress. Avoid including secrets or sensitive personal information in exercises or public bug reports.

Local records are controlled by the user and can be removed through their normal file management workflow. Uninstalling a plugin does not imply deletion of learning files or provider-side conversation history. This repository's `.gitignore` excludes normal local learning directories; it is not a substitute for reviewing files before publishing.
